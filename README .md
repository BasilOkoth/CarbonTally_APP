
CarbonTally – Tree Monitoring & Impact Measurement Platform
CarbonTally is a community-driven digital platform that transforms tree planting initiatives into measurable, accountable, and data-driven conservation programs. It allows schools, communities, NGOs, and donors to track tree planting, monitor survival, analyze data, and visualize conservation impact.
Key Features
•	Tree Registration & Monitoring: Capture tree location, species, and planting date.
•	Dashboards & Visualization: Track survival rates, total number of trees planted and species diversity.
•	Public-Facing Transparency: Donors can verify contributions and see impact.
•	Community Empowerment: Students and communities digitally “own” trees.
•	Field agent portal: A user dedicated portal used by the field agents during tree planting and monitoring
•	Find Nearby Tree: An innovative feature in the Field Agent Portal that helps locate trees during monitoring when QR codes are missing, not yet tagged, or inadvertently misplaced
•	Plant A Tree button: A feature within the User dashboard for checking new submissions from the field during tree planting.
•	Monitor Trees: A feature within the User dashboard for checking new submissions from the field during tree monitoring. 
•	Field Agent Access: a section within the user dashboard for generating field password during tree planting or monitoring
•	Tree IDs: Unique IDs for each tree to facilitate monitoring, adoption, and reporting.
•	QR codes: QR codes automatically assigned to planted trees at planting. The user is supposed to tag each tree to its associated QR tags
•	Tree tracking number: A unique ID assigned to each user who signs to CarbonTally. It is used to login to the Field Agent Portal to track all the trees planted under it back to the use
•	Tree Tracking Password: A 24-hour, one-time password generated by the admin each time a tree planting event is organized. It allows secure access to the Field Agent Portal during tree planting or monitoring activities.
KoBo Toolbox Integration
Purpose
CarbonTally integrates with KoBo Toolbox to:
1.	Launch tree planting forms from the application.
2.	Capture geolocation, species, and growth data.
3.	Generate unique tree IDs and QR codes.
4.	Automatically store all submissions in the CarbonTally database.
Setup Instructions
1.	Create a KoBo account (https://www.kobotoolbox.org) and build your tree planting form with required fields (institution, species, student, date, tree stage, geolocation, etc.).
2.	Deploy the form and note the Asset ID.
3.	Generate an API token from KoBo account settings.
4.	Update app.py and kobo_integration.py with the KoBo API URL, token, and asset ID.
5.	Ensure the data/ and data/qr_codes/ directories exist and are writable.
Usage Instructions
Plant a Tree:
1.	Log in as admin, institution user, or Individual.
2.	Navigate to Field Agent Access and generate Field Agent password
3.	Navigate to Field Agent Portal, and login using your tree tracking number starting with CT- XXXXXXXX, and password 
4.	Navigate to Plant A New Tree, and click the Fill planting Form button
5.	Complete the KoBo form, including geolocation.
6.	Submit 
7.	CarbonTally fetches new submissions when you click check new submissions and generates a tree ID and QR code, and stores data in the database.

Data Flow Overview
1.	User launches KoBo form via CarbonTally.
2.	Form data is submitted to KoBo.
3.	CarbonTally queries KoBo API for recent submissions.
4.	Data is processed: mapped to database, tree ID generated, CO₂ calculated, QR code created, and stored.
5.	Dashboards and analytics update in real time for stakeholders.
